# MediaPipe person detector model

`person_detection_mediapipe_2023mar.onnx` is obtained from the
[OpenCV Model Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/person_detection_mediapipe).

The model and the corresponding OpenCV Zoo example are distributed under the
Apache License 2.0. The upstream repository documents that the model detects
upper-body and full-body landmarks and is based on MediaPipe Pose.
